# Asterix Backend

Express API and SQLite database service powering the Team Asterix portal.

For the complete technical guide, architecture diagrams, database schema definitions, and API specifications, see:
👉 **[BACKEND.md](../BACKEND.md)** in the project root.

## Quick Start

```bash
# Copy environment variables
cp .env.example .env

# Install dependencies
npm install

# Start development server
npm run dev
```
